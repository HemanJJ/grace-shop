平常會做的四件事

① 改價錢 / 改商品說明

  1. 工作台 → 本機後台 → 商品
  2. 改完存檔
  3. 按 🚀 發布上線（它會先同步價錢到收單系統，再推網站）
  4. 到 /orders 下一張測試單，看金額對不對

② 新增一個商品

  1. 開 /sheet 填：商品名、三句賣點、售價、進價、階梯
  2. 選一張圖（表單會自動縮圖上傳，狀態出現「✅ 圖已上傳」才算成功）
  3. 按複製，貼給小李
  4. 我建檔 → 同步 → 上線，回你網址

③ 錄一集新故事

  1. 控音台：貼上稿子 → 按「生成」
  2. 下載 mp3 → 放到 `mp3/`（檔名照 `01_篇名_標題.mp3`）
  3. 本機後台 → 故事 → 填該集 → 發布

④ 開完團、要叫貨

  1. 開 /orders，選日期
  2. 看最下面的「叫貨清單」：每樣商品今天總共幾件
  3. 照那個數量叫貨（不用再自己加總）

資料放在哪（要備份就抓這幾個）

檔案 / 資料夾是什麼
products.json商品主檔（含進價、售價、箱入數、圖片路徑）
tiers.json量價階梯（滿幾件打幾折）

images/商品圖（檔名用商品編號開頭）
mp3/故事語音
dist/上線用的整包（不要手改，由後台發布產生）
Cloudflare D1訂單＋庫存價錢（線上資料庫，透過後台同步）

出事怎麼查（照順序）

症狀先看這裡怎麼解
網站開不起來grace-coffee.pages.dev看是不是自己網路；換手機網路試
改完價錢，結帳金額不對本機後台 → 發布按「🔄 同步價錢到收單系統」再試
商品卡沒圖images/檔名要跟 products.json 的 img 一致
後台發布失敗終端機訊息多半是 Cloudflare 登入過期，重新授權一次
控音台打不開工作台雙擊工作台，它會自己叫起來

三件不要做

  1. 不要拖曳上傳網站。正式內容在 dist/，拖錯會蓋回舊版。一律用後台「發布」。
  2. 不要把密碼貼進群組。看單密碼等於營收。
  3. 不要同時改兩個系統。這個站（電台）跟 smartlocker（球館）是兩套。

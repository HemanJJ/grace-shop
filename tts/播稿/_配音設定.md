# 十集電台稿｜給 Qwen3-TTS 控制台

這批是「古早收音機帶貨」版的正式播稿，一集一檔，直接整檔貼進 `work/tts_console` 就能產聲。

## 一、貼稿方式

- 一集一檔：`ep01.txt` ～ `ep10.txt`（一集 389–693 字，遠低於 6000 字上限）。
- 檔內的**空白行＝段落停頓**，請把段落停頓設在 **600–800 ms**。
- 我已經把「開場白 → 故事 → 經文 → 工商服務 → 收尾」拆成段落，不要自己再切。
- 這是**單人旁白**，不是雙人訪問稿，所以不用 `主持人：` / `受訪者：` 標籤。

## 二、建議聲線設定

| 項目 | 建議值 | 說明 |
| :--- | :--- | :--- |
| 聲線 | `uncle_fu` | 你已驗證過的 50 歲沉穩男聲，跟「電台主持人」最合 |
| 語氣描述 | 50歲男性，聲音低沉厚實、沉穩、語速偏慢、溫暖可信 | 你 HANDOFF 裡那組，直接沿用 |
| 語速 | 0.85–0.90 | 長輩聽得清楚比快重要 |
| 段落停頓 | 600–800 ms | 故事換段要留白 |
| ddpm_steps | 50 | 你原本的設定，不要降 |
| 後製 | `atempo=0.90`（可選） | 已在語速調慢者不要再套 |
| 輸出 | 192 kbps／44.1 kHz／立體聲 MP3 | 與正式站一致 |

## 四、為什麼要換掉現在的音檔

目前站上的十集是 **edge-tts**（微軟 Edge 的線上朗讀服務，聲線 `zh-TW-YunJheNeural`）產生的：

- 免費、不用金鑰、快，適合打樣。
- 但**不能指定年齡、情緒、停頓**，也**不能固定一個「主持人聲音」**。
- 商用授權不明確，大量用在帶貨頁面有風險。

Qwen3-TTS 是本機模型，聲音可以固定、語氣可以複製。200 集要聽起來像同一個主持人，這是唯一可靠的做法。

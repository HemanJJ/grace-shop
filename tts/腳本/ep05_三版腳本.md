# 第 5 集｜三種人稱腳本

> 同一篇故事，三種說法。選哪一版，看你要放在哪裡。

## 版本對照

| 版本 | 人稱 | 給誰聽 | 用在哪 | 字數 |
| :--- | :--- | :--- | :--- | ---: |
| A 旁白 | 第三人稱 | 聽眾是旁觀者 | 故事頁主播放、QR Code 掃碼聽 | 693 |
| B 自述 | 第一人稱 | 聽眾是他本人 | 深夜時段、個人化推播、長輩自我認同 | 509 |
| C 訪問 | 第一＋第三 | 聽眾像在旁聽 | 主打集、電台節目、社群分享 | 1114 |

**選用原則**
- A 最安全，適合當預設。
- B 最親，但**要標「改編故事・人物化名」**，否則聽眾會以為是真人自述。
- C 最好聽，但製作成本最高（兩個聲音、26 段）。

## A 第三人稱旁白（現行主稿）

```text
各位聽眾朋友，大家好，我是阿光，歡迎轉到恩典頻道，現在時間，暗時九點。今天要講的，是一位七十六歲的老牧師。師母走了三年，但是他每天早上六點半，還是會泡一杯熱咖啡，放在對面那張空著的藤椅前。

牧會整整四十年，林牧師握過無數病床前顫抖的手，安慰過無數傷心的家庭。但三年前，相伴半世紀的師母安息主懷後，那間曾經充滿笑聲與飯菜香的老公寓，突然安靜得讓人害怕。林牧師回憶說：「那陣子，我每天早上四、五點就醒來，看著對面空著的藤椅，心裡想著，我都七十六歲了，孩子們都在外地忙，接下來的日子，我還要為誰早起呢？」
直到有一個下雨的清晨，他在整理師母留下的大字聖經時，翻到一張夾在詩篇二十三篇裡的手寫字條，上面是師母熟悉的字跡：「老伴，日子如何，你的力量也必如何。我先去天家等你，你早上起來，記得先喝杯熱的暖暖胃，再為教會的弟兄姊妹禱告。」那一刻，林牧師老淚縱橫。他走進廚房，燒了一壺開水，慢慢沖了一杯師母生前最愛聞的溫和中焙濾掛咖啡。當熱氣與焦糖香瀰漫在客廳裡，他第一次在孤單中，深深感受到了從天上來的擁抱與平安。

聖經箴言十章二十二節說：「耶和華所賜的福使人富足，並不加上憂慮。」願主耶穌的平安，今天早晨隨著這杯熱飲，暖進你的心裡。阿們。

故事講到這裡。接下來，是今天的工商服務時間。

聽眾朋友，你也想要每天早上，有一杯熱咖啡，陪你好好跟天父說說話嗎？這組「牧者的晨更陪伴」，是半低因的濾掛咖啡。我們特別把林牧師這段見證，錄成一段語音，印在每一包十乘十二公分的外袋上。手機一掃，就有林牧師的聲音，陪你過一個平安的早晨。一盒十包，四百九十元。教會團購五盒，另外有優惠。買給自己，或是送給獨居的老朋友，都很合適。
```

## B 第一人稱自述（林牧師自己說）

```text
大家好，我是林牧師，今年七十六歲，牧會四十年。今天要講的，是我家客廳那張藤椅的故事。

三年前，陪伴我半世紀的師母安息主懷。那間公寓，以前有飯菜香、有笑聲，後來安靜到會怕。我每天早上四點、五點就醒來，第一個看到的，就是對面那張空著的藤椅。我心裡想，我都七十六歲了，孩子們都在外地忙，接下來，我還要為誰早起呢？

有一個下雨的清晨，我在整理師母留下的大字聖經。翻到詩篇二十三篇，裡面夾著一張字條，是她的字。她寫：「老伴，日子如何，你的力量也必如何。我先去天家等你，你早上起來，記得先喝杯熱的暖暖胃，再為教會的弟兄姊妹禱告。」

我看著那張字條，眼淚止不住。我走進廚房，燒了一壺開水，慢慢沖了一杯咖啡。那是她生前最愛聞的味道，溫和中焙的濾掛。熱氣一上來，焦糖的香味整個客廳都是。那一天，我第一次在孤單裡面，感覺到有一個擁抱，從天上來。

現在，我每天早上六點半，泡一杯半低因的濾掛咖啡。一邊喝，一邊拿著名單，為長青團契的老朋友，一個一個提名禱告。年紀大了，喝咖啡不是為了提神趕路，是為了陪自己，好好跟天父說說話。

聖經箴言十章二十二節說：「耶和華所賜的福使人富足，並不加上憂慮。」願主耶穌的平安，今天早晨，隨著這杯熱飲，暖進你的心裡。阿們。
```
